# Sistema de Login em Java

Projeto acadêmico desenvolvido em Java com interface gráfica usando Swing e banco de dados SQLite.

## Funcionalidades

* Login com validação de usuário e senha
* Bloqueio após 3 tentativas incorretas
* Temporizador mostrando tempo restante do bloqueio
* Reset automático das tentativas após login bem-sucedido

## Tecnologias utilizadas

* Java
* Swing
* SQLite
* JDBC
* NetBeans

## Estrutura do projeto

src/teladelogin/

* BancoDados.java
* Main.java
* TelaLogin.java
* Usuario.java
* UsuarioDAO.java

## Objetivo

Aplicar lógica de programação, estruturas condicionais, controle de estado e manipulação de banco de dados.
